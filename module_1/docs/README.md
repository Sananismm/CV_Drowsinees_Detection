## Project rules

- The interface contract is not frozen until SG-2 and SG-3 accept it.
- Desktop results are not Jetson results.
- Coverage is not accuracy.
- A configured confidence threshold is not an observed confidence score.
- Raw driver footage must not be committed without permission.
